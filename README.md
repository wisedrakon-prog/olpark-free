# 올팍프리 (OLPARK FREE)

**Live:** https://wisedrakon-prog.github.io/olpark-free/

공공데이터 기반 **문화·체육 약자의 이용 장벽 해소를 위한 AI 맞춤형 무장애 활동 지원 플랫폼** — 웹앱 시제품입니다.

올림픽공원을 찾는 휠체어 이용자, 고령자, 영유아·유모차 동반 가족, 임산부 동반 방문자가
"어느 문으로 들어가고, 어디에 세우고, 어디서 빌리고, 오늘 어디가 막혀 있는지"를
방문 전에 한 장의 안내문으로 확인할 수 있게 합니다.

## 무엇을 하는가

| 기능 | 내용 |
| --- | --- |
| 1. 이용자 조건 | 휠체어 이용 / 고령자 동반 / 영유아·유모차 동반 / 임산부 동반 (복수 선택) |
| 2. 목적·교통 | 공연 관람(실제 공연 선택) · 산책 · 실내 체육활동 / 지하철 · 자가용 · 버스 |
| 3. 맞춤 안내문 | 추천 진입문·주차장, 장애인 주차구역 면수, 주차 50% 할인 적용 여부, 휠체어·유모차 대여 위치와 운영시간, **수유실 운영 중지 경고와 대체 장소**, 기상 조건별 실내 대안, 도착·출차 시간, 현장 확인 필요 항목, 출발 전 체크리스트 |
| 4. 장벽 제보 | 방문객이 시설별 불편을 제보하면 즉시 목록에 반영 |
| 5. 관리자 인사이트 | 시설별 불편 건수 막대 차트, 불편 정도·취약 조건 가중치 기반 개선 우선순위, CSV 내려받기 |

안내문은 인쇄하거나 복사해 방문 당일 들고 다닐 수 있습니다.

## 실행

정적 사이트입니다. 빌드나 서버가 필요 없습니다.

```bash
# 로컬에서 열기
python3 -m http.server 8000
# http://localhost:8000
```

`index.html`을 직접 열어도 동작합니다.

## 구성

```
index.html          화면 구조
css/style.css       스타일(큰 글자 모드, 인쇄 스타일 포함)
js/data.js          공연·시설·주차·대여·수유실·강좌 데이터와 출처
js/app.js           조건 선택, 안내문 생성 규칙, 제보 저장, 관리자 집계
```

## 접근성

- 모든 조작 요소 최소 44~48px 터치 영역, 키보드 포커스 링, 본문 바로가기
- 「큰 글자」 모드(100% / 118%)
- 결과 영역 `aria-live` 알림, 표에 `scope` 지정
- 인쇄용 스타일로 안내문만 깔끔하게 출력

## 알려진 한계 (시제품)

- 제보는 브라우저 저장소에만 보관됩니다. 실서비스에서는 공단 민원 시스템(고객의 소리)과 연동합니다.
- 실시간 혼잡도·주차 잔여 면수·수유실 운영 상태는 아직 공개 API가 없어 규칙 기반으로 안내합니다.
- 경사로 각도·단차·보행로 폭 등 미공개 정보는 표시하지 않고 '현장 확인 필요' 배지를 답니다.
